SalesSavvy – Full Stack E-Commerce Application

Spring Boot React MySQL JWT Razorpay Spring Security Vite Axios Hibernate REST API

Problem

Building a production-ready e-commerce platform requires secure authentication, real-time cart management, payment processing, and role-based access — all working seamlessly together. Existing tutorials only covered individual pieces, not a complete integrated system.

Approach

  • Designed a stateless JWT authentication system using Spring Security with HttpOnly cookies to prevent XSS attacks
  • Built a custom AuthenticationFilter that validates every request — checking JWT signature and token existence in database
  • Implemented role-based access control separating Admin and Customer workflows across 25+ REST APIs
  • Integrated Razorpay payment gateway with HMAC-SHA256 signature verification for tamper-proof transactions
  • Designed 8 relational MySQL tables with proper foreign key constraints for users, products, cart, orders, and payments
  • Built a React frontend with real-time cart updates, category filtering, and Razorpay checkout popup

Tools & Technologies

  • Java 17 & Spring Boot 3
  • Spring Security & JWT Authentication (HS512)
  • Hibernate ORM & Spring Data JPA
  • MySQL 8 — 8 relational tables
  • React 18, Vite, Axios, JavaScript
  • Razorpay Payment Gateway
  • Maven, Git, Postman

Key Insights

  • HttpOnly JWT cookies prevent JavaScript access — critical protection against XSS token theft
  • @Transactional annotation ensures atomic DB operations — deleteByUser and save must run in same transaction
  • JWT token column must be TEXT not VARCHAR(255) — HS512 tokens exceed 400 characters causing silent truncation
  • Razorpay HMAC-SHA256 signature verification prevents payment tampering — order_id + payment_id signed with secret key
  • Vite proxy forwards /api and /admin to Spring Boot — eliminates CORS issues during development

Challenges & Learnings

  • Debugged silent JWT truncation — token stored in DB never matched cookie due to VARCHAR(255) column limit
  • Managed lazy loading — accessing FetchType.LAZY fields outside transaction throws LazyInitializationException
  • Foreign key delete order — deleting user requires clearing jwt_tokens and cart_items first to avoid constraint violations
  • Learned end-to-end payment flow — from Razorpay order creation to signature verification to order persistence
